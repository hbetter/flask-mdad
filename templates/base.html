Nachhaltiges Webdesign

Nachhaltiges Webdesign

Diese Website wurde nicht mit WordPress gebaut, sondern bewusst mit schlankem, sauberem Code umgesetzt – ganz ohne unnötige Plugins, externe Skripte und Datenballast. Jeder Seitenaufruf verbraucht dadurch deutlich weniger Energie: Während eine durchschnittliche Website weltweit rund 0,8 Gramm CO2 pro Aufruf erzeugt, setzen wir gezielt auf Reduktion statt Aufblähung.

Betrieben wird die Seite auf einem Cloudserver von Hetzner, deren Rechenzentren bereits seit 2008 zu 100 % mit Strom aus Wasserkraft laufen, bei einem PUE-Wert von 1,13, einem der besten der Branche.

Neugierig, wie grün eine Website wirklich ist? Mit Tools wie dem Website Carbon Calculator oder dem Green Web Check lässt sich der CO2-Fußabdruck jeder beliebigen Seite überprüfen – auch dieser hier.
